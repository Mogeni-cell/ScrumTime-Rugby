# ScrumTime Rugby

## Project Overview

ScrumTime Rugby is a web application that allows rugby fans, teams, and organizers to view and manage rugby matches. Users can:

- See upcoming matches
- Track played games
- View match details like date, time, venue, status, and score
- Add new matches through a simple form
- Delete matches if needed

This solves the problem of fans missing match updates and provides a centralized, interactive way to follow rugby fixtures.

## Features

- Responsive design (works on mobile, tablet, desktop)
- Interactive DOM manipulation using JavaScript
- Form validation and user feedback
- Data persistence via `localStorage`
- Organized display of matches (upcoming and played)

## Technologies Used

- HTML5
- CSS3
- JavaScript (DOM manipulation, event handling, localStorage)

## Known Bugs / Improvements

- Currently no edit functionality for matches
- Could add search or filter features for better match navigation
- Images for teams/venues could enhance visual experience

## Project Structure

index.html - Home page showing upcoming matches
matches.html - Page showing all matches
add-match.html - Form page to add new matches
about.html - About page with project info
style.css - Styling for all pages
app.js - JavaScript logic for match management

## Usage

1. Open `index.html` to view upcoming matches.
2. Open `matches.html` to see all matches.
3. Open `add-match.html` to add a new match.
4. Data persists automatically in your browser's `localStorage`.
